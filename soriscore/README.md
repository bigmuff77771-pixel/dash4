# 소리악보 · SoriScore

반주 없는 한 사람의 노래를 브라우저 안에서 채보하는 무료 웹사이트입니다. React, Vite, VexFlow, jsPDF를 사용하며 외부 AI API 키나 서버가 필요하지 않습니다.

## 사용법
1. 곡 제목과 대략적인 속도(BPM)를 정합니다.
2. 마이크 녹음을 시작하고 브라우저의 마이크 권한을 허용합니다. 반주 없이 한 음씩 부른 뒤 종료합니다. 또는 WAV 등 브라우저가 지원하는 음원을 업로드합니다.
3. 음표의 음정과 길이, 쉼표를 확인합니다. 속도 추정이 나타나면 참고하여 다시 채보할 수 있습니다. 다시 채보하면 수동 편집과 가사가 교체됩니다.
4. 가사를 입력하고 ‘가사 음표에 배치’를 누릅니다. 공백이 있으면 단어별로, 없으면 글자별로 배치하며 각 음표에서 수정할 수 있습니다.
5. 재생으로 확인하고 PDF 다운로드, 인쇄, MusicXML 또는 프로젝트 JSON으로 저장합니다.

## 한계와 개인정보
- 자동 가사 인식은 제공하지 않습니다. 브라우저 음성 인식은 외부 서버를 사용할 수 있으며 노래 가사의 정확한 인식을 보장하지 않습니다. 수동 입력으로 외부 AI API 없는 조건을 지킵니다.
- 단선율 전용입니다. 반주·화음·여러 사람의 목소리, 빠른 음표, 같은 음의 연속 발음, 비브라토에서 오류가 날 수 있습니다. 결과를 직접 수정해주세요.
- 박자표는 4/4 고정, 음정 범위는 C2~C7, 길이는 16분음표 단위입니다. BPM 추정은 참고용이며 반·두 배 속도로 추정될 수 있습니다. 전체 노래의 박자표나 당김음을 완벽하게 인식하는 기능은 아닙니다.
- 한 번에 4분, 파일 크기 50MB, 최대 음표 500개입니다. 마이크 입력은 실시간 음정 분석에 사용하고 원본 녹음 파일로 저장하지 않습니다.
- 음성과 가사는 서버에 업로드하지 않습니다. 프로젝트는 현재 브라우저의 로컬 저장소에 자동 저장됩니다. 다른 기기에서는 JSON 프로젝트를 불러오세요. 공용 기기에서는 브라우저의 사이트 데이터를 지워주세요.
- PDF는 오선지를 이미지로 넣어 생성합니다. 재편집에는 JSON 또는 MusicXML을 사용하세요.
- Chrome/Edge 최신 버전을 권장합니다. 실제 마이크 동작은 기기 권한과 HTTPS 또는 localhost 접속이 필요합니다.

## Windows에서 처음 실행하기
1. https://nodejs.org 에서 Node.js LTS를 설치합니다. 설치 후 새 터미널을 엽니다.
2. GitHub에서 `Code → Download ZIP`을 누르고 ZIP을 풉니다.
3. 압축을 푼 폴더의 `soriscore` 폴더에 들어갑니다. 폴더 주소창에 `cmd`를 입력하고 Enter를 누릅니다.
4. 아래 명령을 한 줄씩 입력합니다.

```text
npm ci
npm test
npm run build
npm run preview -- --port 5173
```

5. 브라우저에서 http://localhost:5173 을 엽니다. 실행 창을 닫거나 Ctrl+C를 누르면 종료됩니다. 이 주소는 내 컴퓨터의 테스트 주소입니다.

일반 개발은 `npm run dev`로 가능합니다. 이 작업 환경에서는 개발용 의존성 분석이 파일 접근 제한에 걸려 `build` 후 `preview`로 검증했습니다.

## Vercel에 배포하기
1. https://vercel.com 에 로그인합니다. GitHub 계정 `bigmuff77771-pixel`의 `dash4` 접근 권한이 있어야 합니다.
2. `Add New → Project`에서 `dash4` 저장소를 가져옵니다. 기존 다른 사이트의 프로젝트는 선택하지 마세요.
3. 프로젝트 이름은 `soriscore`, **Root Directory는 `soriscore`**, Framework Preset은 `Vite`로 지정합니다.
4. Install Command `npm ci`, Build Command `npm run build`, Output Directory `dist`를 확인합니다. 환경 변수는 필요 없습니다.
5. Deploy를 누르고 Ready가 되면 생성된 HTTPS 주소를 엽니다. 공개 사이트이며 방문자 각자의 기기에서 녹음·분석합니다. 무료 요금제의 사용 한도와 이용 조건은 Vercel 계정에서 확인하세요.
6. 실제 주소에서 마이크 권한, 녹음 종료, 편집, 재생, PDF 다운로드를 확인합니다. 배포 주소는 성공한 뒤 Vercel이 제공하는 주소를 사용합니다.

이 저장소의 루트에 있는 기존 `index.html`은 변경하지 않습니다. `soriscore` 폴더만 독립 배포합니다. 연결된 도구의 프로젝트 생성 요청은 2026-11-17에 Vercel 403(생성 권한 부족)으로 거부되어 인터넷 배포 완료 상태가 아닙니다.

## 검증
`npm test`는 합성 음원의 음정·반음·무음·쉼표·박 길이·마디 분할·붙임줄·입력 검증·XML 이스케이프·속도 추정을 검사합니다. 테스트용 WAV와 JSON이 생성됩니다.

브라우저에서 가사 배치, 음정·길이 수정과 PDF 다운로드를 확인했습니다. PDF를 렌더링해 음표와 한글 가사의 표시도 확인했습니다. 실제 사람이 부른 마이크 녹음의 정확도, 여러 모바일 브라우저, 장시간 입력은 검증하지 못했습니다. 파일 업로드 자동 조작은 도구 지연이 발생하여 성공으로 기록하지 않았습니다.
